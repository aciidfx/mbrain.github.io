WORK BRAIN - PHONE VERSION

1. Put this whole folder on any free static web host (GitHub Pages, Netlify, Cloudflare Pages).
   The app contains no data. Your notes stay on each phone, never on the host.
2. Open the web address on your phone.
   iPhone (Safari): Share button > Add to Home Screen.
   Samsung/Android (Chrome): menu (three dots) > Add to Home screen / Install app.
3. Open it from the new Home Screen icon.

Your phone and computer keep separate copies of your data.
To move notes between them: Export backup on one, Import on the other, or use Share.
